How it works

Mandate-gated autonomous payments

An agent wallet is an Algorand account rekeyed to Rocca — an institutional signing service. The human owner grants spending authority via a mandate: a signed permission with configurable caps. The agent spends within those caps autonomously; Rocca refuses anything outside them.

📋

Mandates

Human-signed permissions: per-transaction cap, per-10-minute cap, daily cap, expiry date, and optional allowed-recipient whitelist. Revocable at any time.

⚡

x402 Protocol

HTTP 402 challenge-response built into the SDK. The agent hits a paywall, builds the Ed25519 proof, and retries — all in one call. No human in the loop.

⛽

Gas Station

No ALGO required to create an agent. The treasury sponsors registration and automatically tops up ALGO reserves. Just deposit USDC and start paying.

🔑

Pera Connect Auth

Owners authenticate with their Algorand wallet via WalletConnect (Pera, Defly, Kibisis). Device passkeys (WebAuthn) supported as a fallback.

🛡

Treasury Guards

Global daily ALGO and USDC outflow caps. Velocity-based drain detection. On-chain reconciliation vs authorised totals. Auto-halt on anomaly.

📡

Price Oracle

CoinGecko ALGO/USD feed (60s cache) dynamically scales gas buffer and top-up amounts — spend stays bounded in USD terms as ALGO price fluctuates.

Quickstart

Agent pays for an API in 3 lines

Install the SDK, point it at your agent's key, call executePayment. The 402 handshake is absorbed automatically.

Install bash 
npm install @algo-wallet/x402-client algosdk
Pay for an API endpoint typescript 
import { X402Client } from "@algo-wallet/x402-client";
import algosdk from "algosdk";

const account = algosdk.mnemonicToSecretKey(process.env.AGENT_MNEMONIC!);

const client = new X402Client({
  apiUrl:  "https://api.ai-agentic-wallet.com",
  agentId: "my-trading-bot",
  account,
});

// Fetches a 402-gated endpoint — handles the payment proof automatically
const result = await client.executePayment({
  url:    "https://some-api.com/data",
  amount: 10_000,  // µUSDC — $0.01
});

console.log(result.data); // API response, payment confirmed on-chain
Register a new agent wallet (one-time setup) typescript 
// POST /api/agents/create — treasury sponsors registration
// No ALGO needed. Wallet is funded, USDC opted-in, and rekeyed atomically.
const res = await fetch("https://api.ai-agentic-wallet.com/api/agents/create", {
  method:  "POST",
  headers: { "Content-Type": "application/json", "X-Portal-Key": PORTAL_KEY },
  body:    JSON.stringify({ agentId: "my-trading-bot" }),
});
const { address, mnemonic, registrationTxnId } = await res.json();
// Save mnemonic — shown once. Deposit USDC to `address` and start paying.
API Reference

Endpoints

Backend served at https://api.ai-agentic-wallet.com

GET /health

System health — Redis, algod, indexer, signing service status and latest confirmed round.

POST /api/agents/create Portal Key

Create a new agent wallet. Treasury sponsors: funds the wallet, opts into USDC, and rekeys to Rocca in one atomic group. Returns mnemonic (shown once) + address.

POST /api/agents/register-existing Portal Key

Register a wallet you already own. Supply agentId + mnemonic. Server handles USDC opt-in and rekey to Rocca.

POST /api/pay X-PAYMENT

Execute a mandate-gated USDC payment. Validates Ed25519 proof, checks mandate caps, signs via Rocca, broadcasts to Algorand. Returns txnId + confirmedRound.

POST /api/agents/:agentId/mandate/create Portal Key

Create a spending mandate. Auth via Pera Connect (WalletConnect) or WebAuthn passkey. Fields: maxPerTx, maxPer10Min, maxPerDay, expiresAt, allowedRecipients, recurring.

POST /api/agents/:agentId/mandate/:mandateId/revoke Portal Key

Revoke a mandate. Requires owner authentication (Pera Connect or WebAuthn). Immediate — agent can no longer use the mandate after this call.

GET /api/agents/:agentId/mandate Portal Key

List all mandates for an agent. Returns active and revoked mandates with cap values in µUSDC and remaining velocity windows.

GET /api/agents/:agentId/history Portal Key

Paginated payment history for an agent. Includes txnId, amount, recipient, mandate used, and Algorand explorer link.

X-PAYMENT header structure json 
// Base64-encoded JSON — built automatically by @algo-wallet/x402-client
{
  "agentId":    "my-trading-bot",
  "amount":     10000,             // µUSDC ($0.01)
  "recipient":  "ALGO58CHARADDRESS...",
  "timestamp":  1708339200,       // Unix epoch, <60s old
  "nonce":       "uuid-v4",         // Single-use replay guard
  "signature":  "base64 Ed25519 sig"  // Over canonical payload bytes
}
Security

Zero-trust by design

Six independent enforcement layers. Any single layer failing blocks the settlement.

🔐

Ed25519 Verification

Every request proves ownership of the agent address via algosdk.verifyBytes(). Signature over (timestamp + nonce + amount + recipient).

📋

Mandate Enforcement

Per-tx, per-10min, and daily USDC caps enforced server-side before signing. Expired or revoked mandates are rejected immediately.

⏱

Replay Protection

Timestamp must be within 60s (with 30s back-skew tolerance). Nonces are single-use, stored in Redis with TTL. Both enforced atomically.

🏦

Treasury Guards

Global daily ALGO and USDC outflow caps. On-chain reconciliation detects key compromise. Velocity drain detection auto-halts the system.

🏃

Rate Limiting

Sliding window rate limits on all public endpoints. Per-IP and per-portal-key caps. In-memory fallback when Redis is degraded.

🔒

Rocca Signing

Agent private keys are rekeyed to Rocca — an institutional signing service. No private key ever touches the application server.
